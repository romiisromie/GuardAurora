# GuardAurora

GuardAurora — офлайн-приложение-компаньон для личной безопасности на Expo и React Native.

## Что умеет текущая MVP-версия

- Хранит доверенные контакты и до 50 событий SOS на устройстве.
- Запускает отменяемый трёхсекундный отсчёт и записывает локальное событие. SOS **не** вызывает экстренные службы и автоматически не уведомляет контакты.
- Открывает приложение телефона для звонка или создаёт SMS-черновик выбранному контакту. Перед отправкой пользователь проверяет и подтверждает сообщение.
- Измеряет общий уровень звука локально, пока включён мониторинг и приложение на экране. Аудио не сохраняется: временный файл, используемый измерителем, удаляется при остановке мониторинга или переходе приложения в фон. Определения звуков и распознавания опасности нет.
- При включённом мониторинге фиксирует три быстрых встряхивания, пока приложение открыто, как локальное событие SOS.
- Запрашивает геолокацию только по нажатию пользователя и может открыть полученные координаты в Google Maps.
- Предлагает справку с заранее подготовленными ответами. Это не ИИ-сервис и не экстренная служба.
- Содержит политику конфиденциальности в приложении и функцию удаления локальных данных.

В приложении нет учётных записей, облачной синхронизации, push-уведомлений, автоматического вызова служб, аналитики, встроенной карты, проверенного справочника безопасных мест и оценки маршрутов. Не полагайтесь на приложение вместо местных экстренных служб.

## Локальный запуск

```sh
npm ci
npm run typecheck
npx expo start
```

## Веб-сборка для Vercel

```sh
npm run build:web
```

Команда собирает Expo Web в `dist`. Веб-версия подходит для предварительного просмотра; разрешения браузера и доступ к датчикам отличаются от iOS и Android.

## Подготовка сборки для магазинов

Добавьте переменные в окружение EAS для production-сборки. Не коммитьте настоящие `.env`-файлы, токены и пароли.

| Переменная | Нужна | Назначение |
| --- | --- | --- |
| `GUARDAURORA_PRIVACY_POLICY_URL` | Да | Публичная рабочая ссылка на политику конфиденциальности. Сначала заполните в ней данные оператора и контакты. |
| `GUARDAURORA_SUPPORT_EMAIL` | Да | Публичный адрес поддержки и запросов о данных, отображаемый в приложении. |
| `SENTRY_DSN` | По желанию | Включает отправку отчётов об ошибках в Sentry. Пустое значение отключает отправку. Если включено, это нужно отразить в политике и формах магазинов. |
| `SENTRY_AUTH_TOKEN` | Только при настройке загрузки source maps | Секретный токен Sentry; сам по себе не включает загрузку карт исходников. Не храните его в Git и клиентском приложении. |

Отчёты Sentry выключены, пока `SENTRY_DSN` пуст. Аналитический SDK не подключён. Не заявляйте, что мониторинг сбоев работает, пока не проверите событие из production-сборки в панели Sentry. Настройка загрузки source maps требует отдельной конфигурации EAS/Sentry.

После публикации политики проверьте ссылку в браузере без входа в аккаунт. Сборки выполняются в EAS:

```sh
npx eas-cli login
npx eas-cli build --platform ios --profile production
npx eas-cli build --platform android --profile production
```

Загрузка сборки в App Store Connect и Google Play Console требует аккаунтов владельца в Apple Developer и Play Console, карточек приложения, signing credentials, заполненных страниц магазина, точных сведений о конфиденциальности, скриншотов и заметок для модерации. Сама EAS-сборка приложение в магазин не публикует.

## Чек-лист перед отправкой

- [ ] Внести юридическое имя оператора и контакты в `src/legal/privacyPolicy.ts`.
- [ ] Опубликовать завершённую политику на стабильном публичном URL и установить `GUARDAURORA_PRIVACY_POLICY_URL`.
- [ ] Указать и проверить публичный адрес поддержки.
- [ ] Решить, включать ли Sentry; проверить production-отчёт и раскрыть сбор данных SDK в формах магазинов.
- [ ] Проверить privacy report iOS и актуальные требования к privacy manifest сторонних SDK.
- [ ] Заполнить возрастной рейтинг, регионы, скриншоты, описание, URL поддержки и privacy/data safety в App Store Connect и Play Console.
- [ ] Проверить на реальных устройствах iOS и Android разрешения, звонки/SMS-черновики, отмену/остановку SOS, офлайн-режим, отказ в геолокации и удаление данных.
- [ ] Выполнить store-сборки и пройти модерацию через реальные аккаунты разработчика.

Изменения исходного кода сами по себе не гарантируют одобрение магазина. Результат зависит от итоговой сборки, сторонних SDK, карточки приложения, данных владельца, проверки на устройствах и аккаунтов разработчика.
